# Raoul Iftode — Portfolio (Vue)

```bash
npm install
npm run dev
```

- `src/views` — pages (`HomeView`, `ParcoursView`)
- `src/components` — reusable UI
- `src/styles/root.css` — design tokens, `base.css` — reset + shared classes
- `src/i18n` — `en.ts` / `fr.ts` messages; the chosen language is saved in `localStorage`
- `src/router` — routes, per-page nav links, hash scrolling
- `src/types.ts` — shared types
